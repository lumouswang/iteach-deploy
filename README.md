# 汤探局 · SaltLake Detective

> 基于"武将卡分工 + 海龟汤"机制的高中理综跨学科交互课件
> 面向高一理科综合题训练，覆盖化学·物理·生物·地理 4 学科 9 个高考考点

## 项目简介

「汤探局」是一个**完整的课堂教学课件**，不是游戏平台。它以山西运城盐湖为真实情境，通过：

- **7 张武将手牌** = 7 个学科思维分工
- **受限标准化提问**（5 次上限，三类选项）
- **双人卡组合 + 层锁汤底**（4 层必须按序解锁）
- **即时分段复盘 + 全局可视化**

让学生在 1 节课（45 分钟）内完成布鲁姆认知 4 层跃迁：
- 现象层（识记）→ 条件层（理解）→ 微观层（分析）→ 终极层（评价/创造）

## 赛道

## 快速启动

### 1. 启动后端（FastAPI）

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

后端将运行在 `http://localhost:8000`

### 2. 启动前端（Vue3 + Vite）

```bash
cd frontend
npm install
npm run dev
```

前端将运行在 `http://localhost:5173`，自动代理 `/api` 到后端。

### 3. 体验流程

1. 打开 `http://localhost:5173`
2. 点击「开始探汤」创建房间
3. 7 张武将卡摊在手里，开始提问博弈
4. 出卡收线索 + 合技解锁汤底
5. 进入复盘页查看全局可视化

## 核心机制亮点（答辩用）

### 1. 武将卡 = 取景器（不是道具）

每张卡的「技能」= 一个学科思维分工，单卡只取**碎片线索**（局部观察）。
两卡配对合技 = 整层汤底（综合推演）。
乱组合 → 强行拒绝，无收益。

### 2. 受限标准化提问（杜绝瞎问）

不开放自由文字提问。海龟汤最大的"瞎问"陷阱被彻底解决：
- **物质类**（"X 是否含 Y？"）
- **环境变量类**（"在 Z 条件下 W 是否成立？"）
- **力学系统类**（"由于 P，系统是否 Q？"）
- 5 次上限 + 否决板自动归集

### 3. 层锁汤底（布鲁姆认知阶梯）

4 层汤底必须**严格按序解锁**：
| 层 | 名 | 对应布鲁姆 | 解锁合技 |
|---|---|---|---|
| 1 | 现象层 | 识记 | 地理合技（徐霞客+沈括）|
| 2 | 条件层 | 理解 | 理数合技（祖冲之+墨子）|
| 3 | 微观层 | 分析 | 转化合技（宋应星+徐光启）|
| 4 | 终极层 | 评价/创造 | 链结合技（李时珍+任意）|

跳过 → 系统拒绝"线索不足，请先解开上一层"。

### 4. 三大可视化复盘

- **否决板**：学生自己的错题本（红字标签）→
- **线索图谱**：思维路径可视化（颜色按学科）→
- **武将图鉴**：学情画像（已点亮武将 = 已掌握学科思维）

## 知识点覆盖

### 化学（6 个考点）
- 溶解度与温度关系
- 多盐共饱和体系
- 结晶水合物（Na₂SO₄·10H₂O）
- 沉淀溶解平衡（Ksp）
- 亨利定律
- Ksp 选择性沉淀

### 物理（3 个考点）
- 蒸发吸热与汽化潜热
- 毛细现象
- 辐射冷却

### 生物（2 个考点）
- 生物化石判定标准
- 嗜盐菌渗透压调节

### 地理（3 个考点）
- 内陆封闭盆地与盐湖
- 蒸发与降水差
- 史料实证（《水经注》反证）

**合计 4 学科 14 个考点**（含必考 + 选考高频）
