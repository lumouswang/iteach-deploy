## 【0:00 – 0:30】背景：跨学科综合题的教学痛点

各位评委老师好。

我们参赛的作品叫《汤探局》。

在高一理综课堂上，**跨学科综合题是最大的拦路虎**——
- 题目创设真实情境，学生读不进去
- 跨度大，化学、物理、生物、地理同时出现，学生理不清
- 学生大多卡在现象层，无法深入微观层

我们要做的，是**一个聚焦 1 道跨学科综合题的交互课件**，让学生在 1 节课内，用 7 张武将卡分工提问 + 合技解锁汤底，爬完布鲁姆认知 4 个层级。

---

## 【0:30 – 2:00】一局实录演示

> **演示动作**：打开 `http://localhost:5173`，进入开局面，进入房间

我们的情境选在山西运城盐湖——一块"贝壳状石头"贯穿全课。学生拿到 4 个反常现象：

> 1. 石头表面有贝壳印，但敲开是空的
> 2. 第二天清晨长出白毛，中午消失
> 3. 丢进水里冒泡，体积缩小一半
> 4. 老师说：这不是化石

7 张武将卡——徐霞客、沈括、祖冲之、墨子、宋应星、徐光启、李时珍——每张卡就是一个学科观察视角：

- 🗺️ 徐霞客看地貌
- ⚗️ 宋应星做化学分析
- 🌿 李时珍反证它不是化石

学生**只能用三类标准化提问**，5 次上限。例如「盐湖水中是否同时含多种盐？」——不是瞎问。这是**物质类 / 环境变量类 / 力学系统类**的强制分类。

系统返回「是 / 否 / 相关」。所有「否」自动进入**红字标签的否决板**——这就是学生的错题本。

接着出武将卡。单卡只能拿碎片线索——比如徐霞客给「运城是内陆封闭盆地」、墨子给「毛细上升 5-10 cm」。

**两卡合技**触发汤底解锁：
- 现象层（地理合技 = 徐霞客+沈括）
- 条件层（理数合技 = 祖冲之+墨子）
- 微观层（转化合技 = 宋应星+徐光启）
- 终极层（链结合技 = 李时珍+任意已用卡）

**关键约束**：4 层必须严格按序解锁。跳层？系统拒绝：「线索不足，请先解开【条件层】真相」。

每解一层，**段级复盘弹窗立刻弹出**，趁热打铁。

## 【2:00 – 2:45】技术亮点速览

后台核心 4 个模块：

- 状态机：7 阶段枚举（INTRO → QUESTIONING → CARD_PLAY → REVEAL → DEBRIEF → EXTEND → END）
- 合技引擎：4 步校验 = 有效配对 + 链结例外 + 上层已解 + 单卡 ≤ 2 次
- 受限提问判定：20 题预设 JSON，公开题面、隐藏答案
- 否决板自动归集：每次「否」答案自动写入

前端用 Vue3 + Element Plus + Pinia，加 Element Plus 直接拿来主义。
