# 《汤探局——基于"武将卡分工+海龟汤"机制的高中理综跨学科交互课件》作品说明书

> 申报赛道：**课件类（赛道二）**
> 副标题：面向高一理科综合题训练，覆盖化学·物理·生物·地理 4 学科 9 个高考考点

---

## 一、作品概述

### 1.1 定位

《汤探局》是一个**聚焦 1 个跨学科综合题的交互课件**，不是游戏平台，不是 OA 工具，不是 AI 模型包装。
它的核心是：**用游戏化的"卡牌机制 + 海龟汤推理"作为外衣，强制学生走完布鲁姆认知 4 层阶梯**。

### 1.2 切入口

高一理综综合题长期痛点：
- **读不懂** —— 真实情境陌生（运城盐湖大部分学生没去过）
- **理不清** —— 跨学科跨度大（化学+物理+生物+地理同时出现）
- **不深入** —— 学生卡在"现象层"无法进入"微观层"

《汤探局》以**山西运城盐湖**这一真实国家级自然保护区为情境——一块"贝壳状石头"贯穿整个 45 分钟课堂，让学生**用 7 张武将卡分工提问 + 合技解锁汤底**，逐层爬升到跨学科整合的"终极层"。

### 1.3 一句话立项

> **"让高一学生在 1 节课内，以玩代学，以问代练，以汤代题，跨过 4 个学科 9 个高考考点。"**

## 二、作品主体内容

### 2.1 教学情境

#### 汤面（剧本杀核心情境）

> 山西运城盐湖是国家级自然保护区。一群高一学生前往野外考察，午间在盐滩上休息。带队老师随手捡起一块"贝壳状石头"让学生辨认。奇怪的是——
>
> 1. 石头表面压出 5 厘米深的"贝壳"形状，但敲开后**内部是空的**；
> 2. 第二天清晨学生再来，发现石头表面**长出了一层"白毛"**，中午又消失；
> 3. 一位同学不小心把石头丢进湖边浅水里，**水里冒泡**，**石头体积缩小了一半**；
> 4. 老师断言：这块石头不可能含有真正的化石。
>
> **请用 5 次提问 + 4 层推演，找出"石头为何有贝壳印但不是化石、为何能冒泡、为何长白毛"。**

#### 4 层真相（学生逐步解锁）

| 层级 | 内容 | 关键词 |
|---|---|---|
| 现象层 | 这块石头是盐湖析出的盐花结核（钙芒硝结核），形状像贝壳是因为结晶速率和湖底气泡共同塑形。| 盐结晶、形态选择 |
| 条件层 | 盐湖水中多种盐共饱和（NaCl、Na₂SO₄、CaCO₃），矿化度高达 100-300 g/L；清晨温度低时毛细管结晶形成"白毛"。| 蒸发、毛细、过饱和 |
| 微观层 | 入水后多盐体系 pH、离子活度变化，原本稳定的结晶态被打破：CaCO₃ 与 Na₂SO₄ 选择性溶解，结晶水合物脱水，伴随 CO₂ 逸出。| 沉淀平衡、Ksp |
| 终极层 | 运城盐湖形成 = 古生代海洋封闭→蒸发岩沉积→现代盐湖；石头本质是**非生物盐湖沉积再造物**，老师用"化石必须有生物矿化结构"反证。| 综合整合、跨学科 |

### 2.2 7 张武将卡（学科思维分工）

| 卡名 | 朝代/身份 | 学科意象 | 主问视角 | 配对合技 |
|---|---|---|---|---|
| 🗺️ **徐霞客** | 明·地理学家 | 内陆封闭盆地、蒸发降水差 | 环境变量类 | +沈括 → 解锁现象层 |
| 📚 **沈括** | 宋·科学家 | 史料反证、《水经注》记载 | 环境变量类 | +徐霞客 → 解锁现象层 |
| ⚗️ **宋应星** | 明·《天工开物》 | 多盐共饱和、结晶水合物 | 物质类 | +徐光启 → 解锁微观层 |
| ⚛️ **徐光启** | 明·《几何原本》译者 | 沉淀溶解平衡、亨利定律 | 物质类 | +宋应星 → 解锁微观层 |
| 🧮 **祖冲之** | 南北朝·数学家 | 蒸发动态模型、过饱和建模 | 力学系统类 | +墨子 → 解锁条件层 |
| ⚙️ **墨子** | 春秋·科学家 | 汽化潜热、毛细现象、辐射 | 力学系统类 | +祖冲之 → 解锁条件层 |
| 🌿 **李时珍** | 明·《本草纲目》 | 生物矿化、嗜盐菌渗透压 | 物质类 | +任意已用 → 解锁终极层 |

每张卡：
- 限用 **2 次**（防止单一视角反复刷线索）
- 背面展示**对应的高考考点**标签
- 鼠标悬停显示技能详情

### 2.3 三大游戏化机制

#### 机制 1：受限标准化提问（杜绝瞎问）

学生不开放自由文字提问，只能从三类标准化选项中挑选：
- **物质类**：「【主体物质 X】是否含【成分/结构 Y】？」
- **环境变量类**：「在【时空条件 Z】下，【环境变量 W】是否成立？」
- **力学系统类**：「由于【机理 P】，系统是否呈现【现象 Q】？」

总共 5 次提问上限。每次提问被系统判定「是 / 否 / 相关」，"否"类自动归集到**否决板**（红字标签），同步提示「该思路偏差，可使用 XX 武将卡定向探查」。

#### 机制 2：双卡合技 + 层锁汤底

不同武将两两配对 → 触发"合技"→ 解锁一层汤底。

**核心约束（层锁）**：
- 4 层必须严格按顺序解锁：**现象层 → 条件层 → 微观层 → 终极层**
- 跳过 → 系统拒绝：「线索不足，请先解开【上一层】真相」
- 每一层解锁瞬间，自动弹**段级复盘弹窗**，总结该层的核心思维视角

#### 机制 3：即时分段复盘 + 全局可视化复盘

**段级复盘**（每层解锁后立即弹窗）—— 趁热打铁巩固该层思维模式。

**全局复盘页**（通关后展示 4 大模块）：

| 模块 | 内容 | 教学价值 |
|---|---|---|
| ① 否决板 | 汇总所有错误猜想 + 对应易错考点 | 学生自己的错题本 |
| ② 线索图谱 | 可视化 14 条线索 → 4 层汤底归属 | 思维路径回溯 |
| ③ 武将图鉴 | 本局使用的武将自动点亮 + 知识点收藏 | 学情画像 |
| ④ 战绩统计 | 提问使用 / 错题数 / 线索收集 / 通关进度 | 量化反馈 |

## 三、技术方案

### 3.1 技术架构

- **后端**：Python 3.11 + FastAPI + WebSocket
- **数据资产**：JSON 文件驱动（4 份核心 JSON）
- **AI 加分项（可选）**：Qwen-turbo API + Edge-TTS

### 3.2 项目结构

参见 `README.md`

### 3.3 关键技术点

#### 3.3.1 状态机（7 阶段枚举）

```python
class GamePhase(Enum):
    INTRO = "intro"                  # 阶段1：开局前置
    QUESTIONING = "questioning"      # 阶段2：海龟汤定向提问
    CARD_PLAY = "card_play"          # 阶段3-4：单/合出卡
    REVEAL = "reveal"                # 阶段5：终极揭晓
    DEBRIEF = "debrief"              # 阶段6：即时复盘
    EXTEND = "extend"                # 阶段7：课后拓展
    END = "end"
```

#### 3.3.2 合技引擎 + 层锁校验

每张卡有 `combo_partner`（链结卡为 `any_with_used_card`）。
合技时进行 4 步校验：
1. 是否为有效合技组合（精确匹配 `combo_table.cards`）
2. 是否为链结合技（G7 + 任意）
3. 上层是否已解锁（强制顺序）
4. 单卡使用次数是否 ≤ `max_use = 2`

#### 3.3.3 否决板自动归集

每次提问返回 `answer == "否"` 时，自动写入房间状态的 `negation_board` 数组。复盘页一键可视化展示。

## 四、教学设计

### 4.1 一节课完整闭环（45 分钟）

| 时间 | 环节 | 学生动作 | 平台状态 |
|---|---|---|---|
| 0–3 min | 导入：汤面 + 任务卡 | 读情境、记考点 | 开局页（IntroView）|
| 3–8 min | 提问博弈 | 选 5 个最关键问题 | 提问面板（≤5次）|
| 8–18 min | 卡牌推演 | 选武将、定向拿线索 | 出卡区 |
| 18–22 min | 合技锁层 | 两人组合触发 | 进度条 + 段级复盘弹窗 |
| 22–25 min | 终极揭晓 | 看完整故事 + 考点对齐 | 双栏展示 |
| 25–40 min | 全局复盘 | 自查错题 + 看图谱 | 复盘页（4大模块）|
| 40–45 min | 课后变式 | 同样思路解决新题 | 拓展题模块 |

### 4.2 教学目标

#### 知识目标
- 掌握 4 学科 9 个高考考点

#### 能力目标
- **批判性思维**：提问的类型选择 + 否决板的自我纠错
- **跨学科整合**：分学科视角 → 跨学科综合
- **认知跃迁**：识记 → 理解 → 分析 → 评价/创造

#### 素养目标
- 通过《水经注》《梦溪笔谈》《天工开物》史料，培养文化自信
- 通过中国历史人物（徐霞客、沈括、宋应星、徐光启、祖冲之、墨子、李时珍）建立民族自豪感

## 五、作品创新点

### 5.1 内容创新：用历史人物打通学科壁垒

| 武将 | 历史身份 | 学科连接 |
|---|---|---|
| 沈括 + 徐霞客 | 宋代、明代地理学家 | 教材中的中国古代科技模块 |
| 宋应星 | 《天工开物》作者 | 中国化学化工思想源流 |
| 祖冲之 | 圆周率计算 | 数学建模的本土文化基础 |
| 墨子 | 墨家学派、《墨经》光学 | 物理学在中国古代的雏形 |
| 李时珍 | 《本草纲目》 | 生物多样性、博物学传统 |

**亮点**：所有武将都是中国人，**跨学科且都是高考涉及的中国古代科技文化**，自然完成"立德树人"。

### 5.2 机制创新：卡牌 = 取景器（不是道具）

传统教育游戏的卡牌是"道具"，学生打完牌只为效果。本课件的卡牌是**取景器**：
- 卡牌本身 = 一个学科观察视角
- 单卡只能获取局部、碎片、线性线索
- 双卡合技 = 多视角整合 → 涌现宏观规律

**这就是布鲁姆"识记→创造"层级跃迁的强制器**。

### 5.3 评价创新：否决板 = 错题本 + 学习仪表

学生每次被系统判定"否"的提问，自动进入**否决板**——这不是惩罚，而是**暴露思维盲区**。

复盘页一键导出 PDF = 家长会、教学研讨可用素材。
